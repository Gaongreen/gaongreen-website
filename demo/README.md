# GaonGreen offline demo (fictional data only)

Generated by `node tools/build-demo.js` from the canonical Cloud Beta pages. Originals are untouched.
- Replaces Supabase with an in-browser stand-in (`vendor/supabase-demo.*`): NOT Supabase, NO real auth, NO real row-level security.
- Replaces the QR library with a local shim built from Kazuhiko Arase's MIT-licensed QR core (`vendor/qrcode-shim.js`, provenance in its header).
- Adds a CSP that blocks every external request, and a yellow DEMO banner with a "Reset demo data" button.
- Sign-in accepts ANY fictional email/password and signs you in as `demo.user@example.invalid`.

Run it (no install, no network): `cd demo && python3 -m http.server 8080`, then open http://localhost:8080/ in a browser.
(Use localhost, not file://, so IndexedDB and storage behave normally.)

Do not describe this as the secured product: it demonstrates screens and calculations only.
