How to use this tool

Enter annual electricity use and renewable electricity amounts in MWh. Count each MWh once only, and use recognized quantities supported by evidence. Results are estimates, not verified claims.

Test with fictional data. Entries are stored in this browser only; clearing browser data may erase them. Export a JSON backup regularly. Do not enter confidential records into this prototype.
