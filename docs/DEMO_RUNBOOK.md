# GaonGreen offline demo: run sheet (fictional data only)

The `demo/` folder is generated by `node tools/build-demo.js` (the full test suite rebuilds it). It needs **no network, no account, no Supabase**.
A built-in stand-in replaces the backend: data lives in this browser's storage only, and a **DEMO banner** is shown on every page. Nothing you enter leaves the machine.

## Start
```
node -e "require('./tests/lib/serve.js').start('demo').then(s=>console.log(s.base))"   # prints http://127.0.0.1:<port>/
```
(or serve `demo/` with any static server on 127.0.0.1). Open `index.html`, language selector top right: English / 한국어 / العربية (RTL).
Sign in with any fictional email/password on the Login page (stand-in accepts it; this is NOT real authentication). Use the top navigation strip to move between tools; **Sign out** ends the demo session.

## Fictional company: "Example Exporter Co." (invented; `example.com` addresses only)
Never type real customer, supplier or personal data into the demo or into screenshots.

| Tool | Enter | Expected result |
|---|---|---|
| Company Settings | Company: Example Exporter Co.; fictional contact | Saves; name appears on other tools/report |
| K-ISSB Wizard | Employees 100; revenue 5,000 (KRW m); electricity 1,000,000 kWh, renewable 250,000; fuel 500; Scope 1 = 120, Scope 2 = 300 | Total 420 tCO2e; 4.2 per employee; renewable share 25%; Save draft, reload, Export JSON, Print/PDF report shows the same numbers |
| K-RE100 Helper | Total consumption 1,200 MWh; PPA 300; REC 200 | Renewable share computed from 500 of 1,200 MWh |
| EPR Packaging Scorecard | 50 g per unit x 1,000 units, 20% recycled content | 50 kg recycled-content weight |
| Supplier ESG Scan | (a) answer all 15 "yes"; (b) mixed answers | (a) 100%, 15 of 15; (b) 63%, 12 of 15, 10 items flagged |
| QR ESG Card | URL `https://example.com/esg`, year 2026, energy 40, emissions 120, recycling 65 | QR renders; downloaded PNG decodes back to the URL |
| Evidence Locker | Upload a small fictional file named "Fictional utility bill", year 2026 | Listed; download returns same bytes; delete works. File is stored in this browser only and is **not** part of the JSON backup (metadata only) |

Cross-checks worth showing: Backup export then Import restores drafts; switching to Arabic flips layout to RTL; narrow window (phone width) stays usable; Sign out returns to Login and protected pages bounce back.

## What to say honestly to a customer
- This is an offline demonstration with a simulated backend. It shows the product behaviour, not the security of the live service.
- Cloud sign-in, per-company data isolation and file-permission rules are a separate staging validation (see STAGING_VALIDATION.md); do not claim they are verified until its result files exist.
